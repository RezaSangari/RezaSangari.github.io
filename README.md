# RezaSangari.github.io

Source for the personal profile website of Reza Sangari Abiz (AI researcher) — live at https://rezasangari.github.io/.

## Preview and deploy

GitHub Pages serves the site from this repository's `main` branch. Any push to `main` redeploys it (allow a minute for the rebuild). To preview locally, open `index.html` in a browser (or serve the folder with any static server).

## Contents

- `index.html` — the whole site (single page)
- `cv.pdf` — the CV linked from the site
- `fonts/` — self-hosted Inter + Source Serif 4 (WOFF2)
- `images/` — photo, social preview, and figures
- `robots.txt`, `sitemap.xml` — search-engine files

## Do not rename this repository

The name `RezaSangari.github.io` is the GitHub Pages user-site pattern: renaming the repository would take the live site at https://rezasangari.github.io/ down. Keep the repository public — GitHub Pages on the free plan requires it.
